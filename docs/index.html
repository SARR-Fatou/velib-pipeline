Comment ça marche

Extract

Python télécharge les flux ouverts GBFS de Vélib' Métropole (référentiel + état des stations).

Transform

Jointure des deux flux, séparation mécaniques / électriques, contrôles qualité et rejet des lignes incohérentes.

Load

Chargement dans SQLite, historisation et calcul des indicateurs en SQL (agrégations, CASE, jointures).

Automatisation

GitHub Actions lance le pipeline et les tests chaque heure, puis publie ce tableau de bord.
